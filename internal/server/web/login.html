This dashboard can rerun and cancel CI and control your runner, so it only opens through a link that cothon creates for you.

To open it in this browser, run in a terminal and paste the link it prints here:

cothon link

Or cothon web (default browser), cothon web --browser firefox. Each browser signs in once, for 30 days; bookmarked filter links keep working afterwards.
