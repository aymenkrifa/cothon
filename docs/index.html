a dashboard for your self-hosted github actions runner

carthage kept its fleet in the cothon, a ring harbour watched from the admiral's tower at its centre. this is that tower for your runner.

reads the runner's own logs — no admin rights, works offline every repo's jobs in one live view, plus what's queued cpu & memory per job, rerun & cancel, runner start/stop
01 · install
~$ go install github.com/aymenkrifa/cothon/cmd/cothon@latest

linux, go 1.24+. the github cli (logged in) is needed for rerun, cancel and the queue — watching works without it. update any time with cothon update.

02 · the web ui

cothon web opens it in your browser and gives your prompt back; the server stops on its own a minute after you close the tab. filters live in the url, so views can be bookmarked.

04 · the runner
cothon runner statusrunning? busy? cpu and memory cothon runner startruns run.sh detached — closing the terminal doesn't stop it cothon runner stopwaits for the current job (--force cancels it) cothon runner logs -fwhat the runner prints, however it was started cothon runner enablestart at login and restart on crash (systemd user service)
